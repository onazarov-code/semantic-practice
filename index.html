More Semantic HTML Practice

What I Did in This Activity

I created this file to practice using semantic HTML tags. I added my name to the meta author tag in the head of the document and linked the CSS file to make the page look better.

I opened this file in the browser to check how it looks and to make sure every tag works correctly. I also reviewed all the content to understand what will be included on the final page.

I followed the steps from class and marked up the text using correct HTML5 tags. I saved and refreshed my page often while coding to avoid mistakes and see my changes live.

Basic Text Tags

I practiced different text tags that add meaning to content. Here are the tags I used:

  • p – for paragraph text
  • em – to emphasize important text
  • strong – for text that shows importance
  • cite – for titles of works
  • mark – for highlighted text
  • b – for drawing attention to text
  • i – for alternate voice or style
  • u – to underline words
  • kbd – to show keyboard input
  • samp – for sample computer output
  • var – for programming variables

I learned that choosing the right tag is important for meaning, not just for style. I used semantic tags to describe what the content actually is, instead of using tags just to make text bold or italic.

Grouping and Headings

I added headings to organize my content and show the structure of the page. I used h1 for the main title, h2 for a secondary topic, and h3 for smaller sections. I also used the section tag to group related content.

  • h1 – main heading, used once per page
  • h2 – subheading under the main topic
  • h3 – smaller subheadings
  • section – container for grouped content

I understood that headings help both users and search engines understand the structure of the content. I organized sections like an outline, making sure each one had only one heading.

Special Characters

I also practiced using special HTML characters to display symbols that normally break code. Here are some examples I used:

  • &copy; – copyright symbol
  • &nbsp; – non-breaking space
  • &amp; – ampersand symbol
  • &lt; and &gt; – less than and greater than signs

I learned that these characters are useful for keeping the code valid and showing special symbols that can’t be typed directly.

Lists

I created both ordered and unordered lists in this project. I used ordered lists for steps and unordered lists for general items.

  • ol – ordered list
  • ul – unordered list
  • li – list item inside a list

I also learned that lists help with accessibility, because screen readers can tell users how many items are in a list. I used nested lists to organize related items clearly.

In the end, I checked my code to make sure I had the correct number of tags and everything was working. I saved all my progress to GitHub using commits, so I could track changes easily.
